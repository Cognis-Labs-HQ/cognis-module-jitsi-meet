# 最終レビューコメントを反映し Whiteboard の安定性を改善

Whiteboard の状態はアクティブなミーティングセッションだけに適用され、ミーティングを開始しただけでは永続キャンバスを開かず、ミーティングの終了または再開時にオープン状態を解除するようになりました。コンポーネントページはミーティングのマウントごとに一度だけ要求し、マウントの再試行回数を制限し、ナビゲーションやミーティング状態によって無効になった古い非同期ウィンドウを破棄します。

キーリングへのアクセスまたはコンポーネントのマウントを待っている間、Whiteboard コントロールは通常のラベルのまま無効になります。コンポーネントウィンドウのマウント成功後にのみ「Whiteboard を閉じる」へ変わり、取り消された古いマウントでは誤解を招く失敗トーストを表示しません。

このプルリクエストのリリースノートは、機能ブランチ名を付けた1組のローカライズ済み Changelog だけを使用するようになりました。コントリビューター向け手順では、ファイル名をブランチの記録とし、既存の Changelog 形式と異なる個別のメタデータブロックではなく、コミットごとに翻訳した説明段落を時系列順で記載することを必須としています。
