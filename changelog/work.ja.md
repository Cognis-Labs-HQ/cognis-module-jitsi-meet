# 安全なミーティング状態の同期

**機能ブランチ:** work

## 権限を持つミーティング状態更新を制限

Jitsi の画面共有状態を報告できるのはミーティング主催者のみになり、独立したエンドポイントを Whiteboard の配下から移動しました。後続のインスタンスが古いロックを引き継がないよう、ミーティングインスタンスの開始時と終了時に画面共有状態をリセットします。

## 参加者の在席フィルタリングを保護

参加者検索では、指定されたミーティングをアクティブな在席フィルタリングから除外する前にアクセス権を確認するようになり、権限のないミーティング ID から在席状況の差異が漏れることを防ぎます。
