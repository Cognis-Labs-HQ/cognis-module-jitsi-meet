# ミーティングチャットのメンバー管理を整合

**機能ブランチ:** work

## 正規の Messages メンバーシップ capability を使用

進行中のミーティングへの招待と参加者の削除で、正規の実行者アカウント ID とユーザーアカウント ID を指定する統一された `social:messages:membership` capability を使用し、現在の Cognis Messages 統合契約に準拠しました。
