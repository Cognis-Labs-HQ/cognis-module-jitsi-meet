# Whiteboard-Ladevorgang stabilisieren

Whiteboards warten nun auf verspätete Provider-, Komponentenfenster- und Schlüsselbund-Capabilities, wenn Teilnehmende eine aktive Besprechung direkt öffnen oder aktualisieren. Komponentenfenster wiederholen vorübergehende Ladefehler und bleiben nach einer fehlgeschlagenen Einbindung für einen bewussten erneuten Versuch verfügbar.
