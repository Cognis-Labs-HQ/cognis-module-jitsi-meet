# コントリビューション基準

## コア指針との整合

リポジトリのコントリビューション手順に、Cognis メインリポジトリから適用可能なアーキテクチャ、セキュリティ、UI、テスト、ローカライズ、バージョン管理、品質の要件を追加しました。

## 独立リポジトリの範囲

モノレポ固有のディレクトリ、Docker、ゲートウェイ、アダプター、Study、中央レジストリの規則は明示的に除外し、関連するアーキテクチャ原則は引き続き適用します。

## リポジトリ準拠

JavaScript の書式を Cognis の 4 スペース Prettier 設定に合わせ、認証対象ルートでは永続化の初期化前に呼び出し元を認可し、一覧 API から未宣言のサーバー側件数制限を取り除きました。Cognis の書式、可読性、曖昧な名前の検査をローカルで実行できるようにしました。意図的なフォールバックは構造化されたコンテキストとともに記録され、ミーティングのセッション識別子には Web Crypto が必須です。

## リリースノートの分離

モジュールの変更履歴を `docs/` の外へ移動し、Cognis のドキュメント検出がリリースノートをモジュールドキュメントとして表示しないようにしました。

## ローカライズ設定メタデータ

マニフェストの設定項目は、モジュールの言語リソース URL から提供される翻訳済み文字列を参照するようになりました。ブラウザーコードはホスト提供のゲートウェイクライアントを使用し、Cognis 由来の品質テストで書式範囲、翻訳キーの一致、タイトル表記、コンポーネント分離を検証します。
