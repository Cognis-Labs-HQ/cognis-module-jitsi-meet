# Jitsi Meet

Cognis からビデオ会議を開催し、参加できます。

## できること

会議の開始、参加者の招待、リンクの共有、チャットを利用できます。Whiteboard が設定されていれば共同キャンバスも使えます。

## 始める前に

管理者が接続可能な Jitsi サーバーを設定し、Meetings を有効にする必要があります。必要に応じてカメラとマイクを許可します。共有リンクには各アクセス条件とパスワード条件が適用されます。

## はじめに

Meetings を開き、必要なら参加者を選んで接続確認を待ちます。Start で会議に入り、共有操作からほかの人を招待します。
