# Jitsi Meet モジュール

[English](README.en.md) · [Deutsch](README.de.md) · [Bahasa Indonesia](README.id.md) · **日本語**

このリポジトリには Cognis 用の外部 Jitsi Meet モジュールが含まれています。ビデオ会議の作成と参加、モデレーション、参加者管理、会議チャット連携、スコープ付きゲスト共有を提供します。

## インストール

Cognis の **モジュール → モジュールソース**からこのリポジトリを追加してモジュールをインストールし、要求されるケイパビリティと依存関係を確認してから、個別に有効化します。有効化すると、アプリケーションルート `/meetings` と `/meeting`、会議ナビゲーション項目、管理セクション、静的ブラウザーアセット、API、ケイパビリティ、フローフックが登録されます。無効化すると、これらのスコープ付きコントリビューションは削除されます。インストール済みモジュールの設定ポップアップで Jitsi インスタンス URLを設定します。Cognis がマニフェストで宣言されたフィールドを表示し、このモジュールが GET および PUT 設定エンドポイントを通じて変更を検証、保存します。

## ケイパビリティと依存関係

このモジュールは `meeting:video`、`meeting:chat`、`meeting:moderation` を公開します。ランタイム連携は Cognis の `ctx` ケイパビリティとフローを通じて解決されます。マニフェストでは、Social ゲートウェイ、Profile アダプター、Share ゲートウェイ、Messages アダプターへの UUID ベースの依存関係と、必要最小限のランタイムケイパビリティを宣言しています。Nextcloud Whiteboard は任意のソフト依存関係として宣言されるため、利用できない場合に Meetings を妨げることなく、Cognis がインストール時に選択肢として提示できます。Cognis の内部パッケージやソースツリーをインポートする必要はありません。

## 開発

`npm install` に続けて `npm test` を実行してください。テストとランタイムコードはリポジトリ相対のモジュールパスのみを使うため、テストスイートは Cognis モノレポの外部でも実行できます。マニフェストは `ui.stringsBaseUrl` を公開するため、Cognis はブラウザー UI が読み込まれる前にモジュールのローカライズ済みメタデータを解決できます。

## セキュリティ

信頼できる HTTPS の Jitsi 環境を使用してください。会議 API へのアクセスには認証が必要で、会議レコードは参加者に限定され、会議ごとにパスワードが生成されます。ゲストアクセスはスコープ付き共有ケイパビリティによって制限されます。有効化する前に、リポジトリと宣言されたファイルダイジェストを確認してください。

ローカルスクリプトはチェックアウト内、または `npm --prefix <checkout> test` で実行し、Cognis のグローバルコマンドとは区別します。導入済み操作は `cognisctl modules:jitsi-meet:ping` です。ブラウザー検証は導入済み Chromium を使います: `CHROMIUM_EXECUTABLE_PATH=/path/to/chromium npm --prefix <checkout> run test:browser`。[統合契約](docs/index.ja.md) とテンプレート由来の AGENTS.md を参照してください。

## アカウント削除の互換性

Auth の `auth:deprovisionOutcome` プロトコル v1 と `system:contracts` を Core の浅く凍結された flow ステージコンテキスト上に導入し、あわせて検証済みゲスト受け入れの依存機能を導入してから、このモジュールを有効にしてください。クリーンアップには、その呼び出しで確定した削除を提供元が確認している必要があります。契約が欠落または不適合の場合、変更可能な入力や公開 flow 結果を信頼せず処理を停止します。ホストの更新だけでは古い Jitsi 連携は保護されないため、両方の更新を調整してください。対象となるホスト候補とリリース順序は、この補完変更の変更履歴に記載しています。合成テストの範囲と失敗時の動作は[連携契約](docs/index.ja.md)を参照してください。
