# Audit Terjemahan Rapat

**Cabang Fitur:** audit-meetings-translations

## Periksa Cakupan Terjemahan

Referensi string modul, label manifes, serta filter, masalah, tindakan, dan konfirmasi administrasi yang dipilih secara dinamis diperiksa menggunakan keempat katalog bahasa sebenarnya. Tidak ditemukan definisi saat jalan lain yang hilang. Contoh notifikasi memakai kunci terjemahan yang tersedia.
