# 検証済みゲストの受け入れ

**機能ブランチ:** `feature-verified-guest-admission`

## 検証済みゲストの受け入れ

会議リソースのルートは `share:getGuestClaims` から検証済みゲストのクレームを取得し、既存の会議と権限の検査を実行します。クレーム全体を `ctx` 経由で Share に渡します。サブジェクトが `share:` で始まるだけではゲストとは判断しません。認証情報や共有許可が存在しない場合、取り消された場合、有効期限が切れた場合も、アカウントのアクセス権に切り替わりません。アカウントと管理用ルートは引き続きセッションを要求し、未完了セッションの制限も維持します。

このモジュールには、Share の検証済みゲスト受け入れ、ゲスト識別、リソース認可の各機能が必要です。モジュールより先に対応する Auth/Share ホスト契約をインストールしてください。ゲストとアカウントが共用するルートでは、セッション専用のホスト側ガードではなくハンドラーで認証を行い、対象会議ごとの認可を維持します。既存の Whiteboard 委任と会議参加の検査は引き続き適用されます。

ゲストの起動時は、認可された会議に対してのみ UI リソースと Whiteboard の利用可否を取得します。認証情報は URL ではなくリクエストのコンテキストで渡します。既存の会議に参加するゲストはアカウント専用の全体事前検査を実行しません。ゲストの応答は作成者の認証操作権限を継承せず、会議パスワードは従来どおり認可済みの参加応答に限定されます。
