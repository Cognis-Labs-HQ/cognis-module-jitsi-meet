# 会議の翻訳を検証

**機能ブランチ:** audit-meetings-translations

## 翻訳の網羅性を検証

モジュールの文字列参照、マニフェストのラベル、動的に選択する管理画面のフィルター・問題・操作・確認文を、実際の4言語のカタログで検証します。実行時に使用する定義の不足はほかに見つかりませんでした。通知の使用例も既存の翻訳キーを参照します。
