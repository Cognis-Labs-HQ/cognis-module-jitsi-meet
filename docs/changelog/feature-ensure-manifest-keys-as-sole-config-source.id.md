# Standar Kontribusi

## Penyelarasan panduan inti

Petunjuk kontribusi repositori kini mencakup persyaratan arsitektur, keamanan, UI, pengujian, pelokalan, versi, dan kualitas yang berlaku dari repositori utama Cognis.

## Cakupan mandiri

Aturan yang hanya berlaku untuk direktori, Docker, gateway, adaptor, Study, dan registri pusat monorepo dikecualikan secara eksplisit, sedangkan prinsip arsitektur yang relevan tetap berlaku.

## Kepatuhan repositori

Pemformatan JavaScript kini mengikuti aturan indentasi dan tanda kutip bersama, rute terautentikasi mengotorisasi pemanggil sebelum menginisialisasi persistensi, dan API daftar tidak lagi memberlakukan batas hasil sisi server yang tidak dideklarasikan. Jalur fallback yang disengaja dicatat dengan konteks terstruktur, dan pengenal sesi rapat kini mewajibkan Web Crypto.
