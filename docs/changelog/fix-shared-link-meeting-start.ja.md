# 参加者なしでリンク共有会議を開始する

**機能ブランチ:** fix-shared-link-meeting-start

## 参加者なしでリンク共有会議を開始する

参加者一覧が空でも単独の会議を妨げません。一覧が空の場合も参加者検索を残し、再描画時に事前確認の結果で開始ボタンを更新できるようにします。事前確認に成功すれば参加者未選択で作成でき、失敗時は引き続き開始できません。準備ガイドは参加者なしでの開始と、参加後のリンク共有を説明します。
