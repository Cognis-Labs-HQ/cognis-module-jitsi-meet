## Pulihkan Tombol Autentikasi

1.5.261 — Tampilan Rapat kini menyediakan label tombol autentikasi dalam keempat bahasa yang didukung. Pengujian regresi merender elemen halaman menggunakan katalog bahasa sebenarnya agar terjemahan templat yang hilang terdeteksi sebelum rilis.
