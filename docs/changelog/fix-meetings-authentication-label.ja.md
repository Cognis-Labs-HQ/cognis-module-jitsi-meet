# 会議ラベルの復旧

**機能ブランチ:** fix-meetings-authentication-label

## 認証操作を復旧

1.5.262 — 会議画面の認証ボタンに、対応する4言語すべてのラベルを追加しました。回帰テストでは実際の言語カタログでページ要素を描画し、テンプレートの翻訳不足を公開前に検出します。

## 翻訳の網羅性を検証

モジュールの文字列参照、マニフェストのラベル、動的に選択する管理画面のフィルター・問題・操作・確認文を、実際の4言語のカタログで検証します。実行時に使用する定義の不足はほかに見つかりませんでした。通知の使用例も既存のキーを参照するようにしました。
