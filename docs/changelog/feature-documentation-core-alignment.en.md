# Documentation and Host Contracts

**Feature Branch:** feature-documentation-core-alignment

## Structured documentation

Info, Usage and Technical are complete localized document families declared by the module manifest. User introductions, practical procedures and current API/configuration contracts have separate views. Strict layout, reference and filename checks run in the standalone suite and CI. Source-file links follow the default branch; changelog labels retain concise commit references.

## Gateway diagnostics

Runtime diagnostics follow the host logging gateway and its output policy. Command reports use terminal streams, and a native-console guard checks module JavaScript, including aliases and computed access. Existing provider ownership, authorization and tutorial completion identities are preserved.
