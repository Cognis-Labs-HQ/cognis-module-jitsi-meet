# 会議検索中の接続断への対応

**機能ブランチ:** feature-offline-transitions

## 会議検索中の接続断への対応

ネットワーク障害が発生すると会議検索の定期取得を停止し、タイマーからの Promise 拒否を処理します。オフラインまたはキャンセルされたリクエストでは検索エラーのトーストを表示せず、最後の会議一覧を保持します。ホストの任意のオフライン状態機能を使用し、後処理はページのシグナルに紐付けます。 進行中の会議のプレゼンスと状態の定期取得も同じライフサイクルに従い、バックグラウンドのリクエストが失敗すると両方を停止します。
