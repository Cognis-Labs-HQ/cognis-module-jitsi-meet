# コントリビューション基準

## コア指針との整合

リポジトリのコントリビューション手順に、Cognis メインリポジトリから適用可能なアーキテクチャ、セキュリティ、UI、テスト、ローカライズ、バージョン管理、品質の要件を追加しました。

## 独立リポジトリの範囲

モノレポ固有のディレクトリ、Docker、ゲートウェイ、アダプター、Study、中央レジストリの規則は明示的に除外し、関連するアーキテクチャ原則は引き続き適用します。

## リポジトリ準拠

JavaScript の書式を共通のインデントと引用符の規則に合わせ、認証対象ルートでは永続化の初期化前に呼び出し元を認可し、一覧 API から未宣言のサーバー側件数制限を取り除きました。意図的なフォールバックは構造化されたコンテキストとともに記録され、ミーティングのセッション識別子には Web Crypto が必須になりました。
